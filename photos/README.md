# Photos

Original Clothsomnia product photos (full resolution), one folder per colourway: `black`, `white`, `off-white`, `olive-green`,
`grey`, `grey-black`, `navy-white`, `burgundy-offwhite`, plus `packaging`. Photos of the hoodie being worn are in each `worn/` subfolder.

Files keep their original camera names (`IMG_xxxx.jpeg`). The prompt packs in `../prompts/` use the Higgsfield reference IDs
(uploaded copies of these photos), not these files directly. Colour values measured from these photos are in `../prompts/colours.md`.

Missing: back-view photos for black, white and off-white (the prompt packs flag this), and a transparent `logo.png`.
